Worked example

"5.NF.B.5 를 배우기 전에 뭘 알아야 해?"

A real run from the live test, traced through each layer.

StepWhat happens
UnderstandThe model returns intent prerequisites, code 5.NF.B.5, no jurisdiction. The text is Korean, so the reply will be Korean.
ResolveThe code exists in several jurisdictions and none was named, so the pipeline answers CLARIFY and asks which one.
Follow-upThe user says "Multi-State". It is validated against list_jurisdictions() and accepted.
Retrieveget_prerequisites follows buildsTowards backward to depth 3 and returns 7 nodes. Ref [1] is the target, refs [2] to [8] are prerequisites.
SynthesizeOne opening sentence about [1], then one bullet per prerequisite, nearest first, each ending in a citation.
VerifyAt least one citation, every [n] is a real ref, and enough prose. It appends the node-id source list and a truncation note.
Check yourself
Which two steps call the LLM?

Understand and Synthesize. Resolve and Retrieve use only KG tools, so the graph decides which nodes count as evidence.

Why can the orchestrator not run its own Cypher?

It may import only common and kg_tools. Queries live in Cypher files, pass the guard, and run read-only.

What happens if the model writes an answer with no citations?

Verify refuses it. The user gets a refusal message, never an uncited answer.
