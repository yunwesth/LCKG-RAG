LearningCommonsRAG Tracker

A graph RAG assistant for teachers and curriculum designers: Neo4j holds the Learning Commons knowledge graph, a local Ollama model answers from it with node-ID citations. Foundation is built and verified and Phase 2 (embeddings and vector indexes) and Phase 3 (typed KG tools) are done and tested: 18 of 33 tracked items done; everything that actually answers a question is still ahead.

Check yourself

Can you read the tracker?

A dotted-border cylinder in blue. What is it?

Data at rest (cylinder) in the knowledge graph entity (blue) that is next up (thick dotted border), such as the vector index.

Why can't the system answer questions by meaning yet, even though Neo4j and Ollama both run?

The embeddings, indexes and the retrieval tools (Phase 3) exist, but the orchestrator (Phase 4) that understands a question, calls the tools and writes a cited answer is not built yet.

Which package is the only one allowed to write to Neo4j?

ingest. It alone uses the admin credentials, and a test fails if any other module references them.
